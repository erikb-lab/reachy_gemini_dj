Reachy Gemini DJ

A voice DJ and tabletop helper for Pollen Robotics Reachy Mini: music, moves, camera, weather, web search and an FRC event helper. Free local voice by default (runs on a computer on your network), with Gemini Live as an optional backup.

Reachy Mini Documentation
Install via Reachy Mini Control → Discover Apps
Or run: reachy-mini-app-assistant check .
